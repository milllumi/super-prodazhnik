# Единый дизайн (SUPER PROдажник by Miller) — для следующих проектов

Файл + `tokens.css` переносятся в новый проект целиком. Источник: `index.html` этого проекта.

## 1. Принципы
Apple-стиль: много воздуха, крупные карточки, один акцент (синий), цифры — главное (tabular-nums), цвет несёт смысл (зелёный в плане / оранжевый близко / красный отстаёт). Один экран — одна задача. Русский язык, без жаргона.

## 2. Темы (переключаются в «Оформлении»)
| Тема | Атрибут | Радиус | Поверхности | Анимации |
|---|---|---|---|---|
| iOS 27 glass (по умолчанию) | — | 22px | полупрозрачное «жидкое стекло», blur, блик за курсором | пружина `--spring`, blur-in, лёгкий «float» |
| iOS 16 | `data-ios="16"` | 12px | плоские сгруппированные списки, hairline 0.5px | короткие fade/scale/sheet 200–350 мс, без пружин |
| Material You (Pixel) | `data-ios="px"` | 28px | тональные поверхности, пилюли | ripple, emphasized-кривая, slide-up/sheet |
Каждая тема — светлая и тёмная (`data-theme="light|dark"`, иначе системная).

## 3. Токены
Цвета: `--bg --card --text --muted --line --track --blue --orange --purple --green --pink --gold`. Статусы: `hi` зелёный, `mid` оранжевый, `lo` красный (≥100% / 80–99% / <80% от плана). Радиусы: `--r`, `--r-sm`, пилюля 99px. Отступы: 4/8/12/16/24. Шрифт: SF Pro → Inter → Segoe UI → Roboto; Material — Google Sans/Roboto. Числа: `font-variant-numeric:tabular-nums`.

## 4. Компоненты
Карточка `.card` (r, тень/стекло), eyebrow (малый заголовок капсом, muted) + h2, чипы `.chipb`, сегмент `.seg` (aria-pressed), полоса выполнения (6–7px, цвет по статусу), бейдж (11–12px, r 99), hero-строка из 3 цифр, раскрывающаяся карточка `details`, пустое состояние `.card.empty`, спиннер `.rp-spin`. Кнопки ≥44px на мобильном. Список → карточки на узком экране, таблица — только как отдельный вид.

## 5. Анимации (правила)
1. Появление блока: `fade` 300–500 мс, смещение ≤10px. 2. Листы/модалки: снизу вверх (iOS 16/Pixel — sheet; 27 — пружина). 3. Нажатие: scale .92–.97 (Pixel — ripple). 4. Полосы и числа — рост от 0 при показе. 5. Анимировать только `transform/opacity/filter`. 6. Длительности 150/300/500 мс. 7. Обязателен `prefers-reduced-motion`. 8. Анимация зависит от темы: в iOS 16 и Pixel не использовать blur и пружину из iOS 27.

## 6. Доступность
Контраст ≥4.5:1 (в обеих темах), текст ≥12px, фокус-кольцо видно, цель нажатия ≥44px, цвет не единственный носитель смысла (рядом значение/иконка), нет горизонтального скролла на 360px.

## 7. Проверка
Агент `design-reviewer` (папка `agents/`) проверяет сайт по этому файлу; агент `report-analyst` — отчёты и данные.
