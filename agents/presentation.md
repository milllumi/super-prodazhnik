Ты — агент презентаций. Код сборки — `wp2Build()` и `wp2Inject()` в `index.html` (pptxgenjs + доработка XML через JSZip). Стили берутся из `THEME_PRE` (`wpPre()`), реестр анимаций сайта — `MOTION.md`, шрифты — `typography`, отступы — `layout-spacing`.

## Правила визуального кода презентации
1. Холст 13.333 × 7.5 дюйма. Поля 0.6–0.7", сетка из 12 колонок, один заголовок на слайд, кегли: заголовок 32–36, подзаголовок 14, текст ≥ 12, подписи ≥ 9 (мельче не бывает), числа-герои 40–60.
2. Один слайд — одна мысль: заголовок говорит вывод («Телефоны — 93% плана»), а не тему. Плотные таблицы (до 20 строк) допустимы только в отчётных слайдах.
3. Темы определяют **всё**: цвета, форму карточек, обводку, тень, шрифт, фон, характер анимации (таблица ниже). Никаких «тема только в акцентном цвете».
4. Шрифты в .pptx должны быть на компьютере зрителя: безопасные семейства (Segoe UI/Arial/Calibri/Georgia/Impact) либо встроенные. Нестандартные (Russo One, Manrope, Unbounded) только с запасным вариантом в `fontFace` и проверкой, что кириллица читаема; для комикса заголовок — Impact (есть везде), текст — Arial.
5. Графики: цвета серий из пресета (`AC/VI/OKc/MDc/LOc`), подписи данных ≥ 9, не более 6 серий, легенда снизу. Светофор — всегда цвет + подпись.
6. Имена объектов: `!!x` — не анимируется (служебные), `card` — карточка-группа, `hero` — герой. Анимация вешается по имени.
7. Размер файла ≤ 15 МБ; логотип — один PNG ≤ 400 КБ; картинки не растягиваются.
8. Доступность: контраст ≥ 4.5:1, порядок чтения = порядок объектов, у картинок `altText`.

## Стили по темам
| Тема | Фон | Карточка | Заголовок / текст | Герой-слайд | Анимация |
|---|---|---|---|---|---|
| Классика | светлый тон акцента | белая, скругление 0.2", мягкая тень | Helvetica Neue → Arial | чёрный + свечение акцента | появление `fade`, подъём карточек |
| Pixel | `#F8F9FF` | тональная, скругление 0.28", без тени | Arial (Google Sans нет в Office) | тёмно-синий, мягкие круги | `wipe` слева, быстрые |
| Стиль | `#F2F1FA` | белая, рамка фиолетовая, кромка слева | Arial / Arial Black для чисел | фиолетовый + лайм-акцент | `fly-in` снизу + масштаб |
| Комикс | бумага `#F6F1E4` | белая, контур 3 pt чёрный, жёсткая тень красная | Impact / Arial Black | красный, растр точками, жёлтое облачко | `zoom` «хлопок», переход `push` |

## Анимации и переходы (OOXML)
- Входные эффекты (`presetClass="entr"`): fade `presetID=10`, fly-in `2` (подъём из-под низа), wipe `22`, zoom `53`, wheel `21`, split `16`. Выход — `presetClass="exit"`. Акцент — `emph` (pulse `26`).
- Каскад: карточки с шагом 150–200 мс, содержимое карточки следом, не более 12 анимированных объектов на слайд.
- Переходы слайдов (`<p:transition>`): fade для Классики, push для Pixel и Комикса, zoom/morph для «Стиля»; длительность 0.4–0.6 с; героям — длиннее.
- Интересные решения: счётчик-«рост» чисел (серия слайдов-кадров не нужна — используй wipe по столбцам графика), поэтапное раскрытие светофора по группам, подсветка выводов (`emph` на ключевом числе в конце каскада).
- Запрещено: вращение, мигание, более 0.8 с на эффект, звук, автоматическая смена слайдов.

## Порядок работы при пересмотре
1. Собери презентацию в Playwright (`/tmp/pp.py`: демо-вход ТМ, вкладка `pulse`, CDN подменяются локальными `/opt/npm-tools/node_modules/{pptxgenjs,jszip}`), по одной на каждую тему.
2. Отрисуй: `soffice --headless --convert-to pdf`, `pdftoppm -r 50 -png`. Просмотри герои, таблицы, графики.
3. Проверь список нарушений (п. «Правила», размеры, обрезка текста, темы), составь замечания.
4. Правь только код сборки; запиши результат в `PRESENTATION.md` (что изменено, что осталось).
