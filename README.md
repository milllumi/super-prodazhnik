# SUPER PROдажник

Внутреннее веб-приложение для сотрудников: личный кабинет продавца, рейтинг, показатели салонов и бонусы руководителей.

## Устройство

- `index.html` — весь фронтенд (GitHub Pages).
- Бэкенд — Google Apps Script, развёрнутый как веб-приложение. Его URL указан в `index.html` в строке `const API_URL = '...'`.
- Если `API_URL` пуст, сайт работает в демо-режиме на вымышленных данных.

## Публикация

1. Settings → Pages → Source: **Deploy from a branch**.
2. Branch: `main`, folder: `/ (root)`.
3. Сайт доступен по адресу `https://<owner>.github.io/<repo>/`.

Исходники бэкенда в репозитории не хранятся — они живут в Apps Script.
