# SUPER PROдажник

Внутреннее веб-приложение для сотрудников: личный кабинет продавца, рейтинг, показатели салонов и бонусы руководителей.

## Устройство

- `index.html` — весь фронтенд (GitHub Pages).
- `Code.gs` — бэкенд Google Apps Script, привязанный к Google-таблице: её ID задан в `CONFIG.SPREADSHEET_ID`.
- `appsscript.json` — манифест Apps Script (часовой пояс, публичный доступ к веб-приложению).
- URL веб-приложения указан в `index.html` в строке `const API_URL = '...'`. Если `API_URL` пуст, сайт работает в демо-режиме на вымышленных данных.

## Как подключается таблица

`Code.gs` открывает книгу `CONFIG.SPREADSHEET_ID` и читает вкладки: «До сотрудника ДЛ», «График», «Доступ», «Детали продаж салоны», «План на день», «Доход сотрудника», «Ссылки», «Новости» (создаётся автоматически), а также «KPI ОСС текущий месяц» по ссылке с вкладки «Ссылки».

Права выдаются вкладкой «Доступ»: A — роль (`новичок`, `птт`, `ртт`, `утт`, `тм`), B — ФИО. PIN сотрудник задаёт сам при первом входе; хранится только хеш в свойствах скрипта, сброс — любой знак в колонке C.

Если на новый месяц меняется книга, обновите `SPREADSHEET_ID` и ссылку «Kpi ОСС текущий месяц», затем разверните новую версию.

## Развёртывание бэкенда

1. В таблице: Расширения → Apps Script, вставить `Code.gs` и `appsscript.json`.
2. Развернуть → Управление развертываниями → Изменить (веб-приложение, запуск от владельца, доступ «Все»).
3. При обновлении кода — выбрать «Новая версия», чтобы URL остался прежним.

## Публикация сайта

1. Settings → Pages → Source: **Deploy from a branch**.
2. Branch: `main`, folder: `/ (root)`.
3. Сайт доступен по адресу `https://<owner>.github.io/<repo>/`.
